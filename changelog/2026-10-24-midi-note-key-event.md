Octatrack base (USB, beta): a new take event, `ev_midi_note_key`, at the point where a MIDI track's note (from its trig, chord or arpeggiator) is about to be corrected to the track's KEY and sent. A module that takes it can rewrite the note or drop it, for its own scales or a scale that changes per step; stock still sends every note-off for the note it sent. It runs in the MIDI sequencer's interrupt, once per note. With no module taking it, every note goes through stock's own KEY correction as before. No module uses it yet; upstream octabam's MIDI Scales patches the same site, so a port of it would take this event instead. The beta base becomes `800ffeb1…` (its USB Audio variants with it); the base-bound packages only follow the new base. On the adapted ColdFire emulator (stock 1.40C, a copied project, MIDI track 1 arpeggiating a chord), the new base sent the same MIDI bytes as stock and the previous base with KEY off, C Major and F Minor, and a test record poked into the event's row turned every note into C with no note left hanging. Not tested on hardware. The base README now says how to build the base in the repository's toolchain image on Linux, and the module guide how a take event's site and tail are written.
